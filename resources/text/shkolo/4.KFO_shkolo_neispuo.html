Връщане към ШКОЛО 


1. Добавяне на учителя към учебните предмети, по които ще води КФО в ШКОЛО:
   - ШКОЛО -> Администрация -> Предмети -> Добавяне на учителя към всички предмети по КФО
   - ШКОЛО -> Паралелки -> Редакция -> Предмети и учители -> Добавяне на учителя към всеки от предметите за КФО

2. Създаване на група в паралелката, в която ще преподава със следните параметри:
   - ШКОЛО -> Администрация -> Паралелки -> Редакция на паралелка -> Групи -> Добави група:
        - тип ИФО
        - име КФО_БЕЛ
        -     КФО_Мат
        -     КФО_ЧО
        -     КФО_ЧП 
        - и т.н.
   - добавяне на ученик към групата за КФО

3. Добавяне на групата за КФО към седмичното разписание:
   - като втора група към седмично разписание + редовен час

4. Редактиране на формата на обучение:
   - ШКОЛО -> Профил на ученика -> Редактирай -> Роля -> Форма на обучение: Комбинирана - за ученици със СОП

5. НЕИСПУО -> Институции -> Учебен план -> Паралелка -> Раздел А -> Добавяне на група:
   - Начин на изучаване -> ЗУЧ-Общообразователна подготовка;
   - Учебен предмет -> БЕЛ, МАТ, ЧО, ЧП и т.н.
   - [v] Индивидуални часове -> Хорариум, според дата на възлагане на часовете и норматив на учителя;
   - Избор на ученик, който се обучава в групата;
   - Избор на учител и дата на възлагане на часовете -> Запази

6. Синхронизиране на групи 
   - ШКОЛО -> Администрация -> МОН -> Синхронизиране на групи -> Избор на клас -> 
     Избор на група в НЕИСПУО, с която да се синхронизира.
