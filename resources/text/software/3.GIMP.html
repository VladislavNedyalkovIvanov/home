                    Премахване на background

Дясно копче въхру layer -> Duplicate Layer -> 
        -> Ctrl + L (за отваряне на Layers)
-> Върху дубликата -> Colors -> Saturation -> 
-> Scale: 0 -> OK -> Colors -> Curves -> 
-> Настройка на линиите по начин, по който всичко да е черно ->
-> Colors -> Invert -> Edit -> Copy Visible -> 
-> Премахване видимостта на копието (оченцето) ->
-> Дясно копче на оригинала -> Add Layer Mask -> 
-> (v) White (Full capacity) -> Add -> Edit -> Paste ->
-> Котвичката долу в дясно (Anchor the floating layer)

   Ако се налага редакция ->
        -> Ctrl + B (за отваряне на меню с инструменти)
-> Gradient Editor -> Обръщане на черно и бяло от стрелките -> Paintbrush -> 
-> Начертаване на видимите зони -> Export -> .png или друг формат.


Видеоинструкция за премахване на Background с помощта на GIMP
