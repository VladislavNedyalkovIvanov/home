            История на Интернет 

- Internet - International Network;
- съвкупност от множество по-малки компютърни мрежи свързани помежду си;
- свързаност между милиони потребители по целия свят;
- отдалечен достъп до информационни ресурси и услуги;
- през 1989 г. в Швейцария е представена концепцията  за World Wide Web (www) от Тим Бърнърс-Лий;
- процесът на развитие, стандартизация и разгръщане на Интернет продължава и до днес;
- Интернет е по същество е информационна система от взаимно свързани хипертекстови документи;
- могат да съдържат текст, изображения, видео и други мултимедийни компоненти;
- преминаването от един документ към друг се осъществява с помощта на хипервръзки;
- информацията организирана в уеб страници се нарича уеб сайт (обединена мрежа от страници);
- уеб браузърът е софтуер, който е предназначен за разглеждане на съдържанието на тези уеб страници;
- URL адресът/уеб адресът е текст, който съдържа местоположението на всяка уеб страница в Интернет;
- много важна част от Интернет са търсачките, без които би било почти невъзможно откриването на сайтове;
- тяхната цел е да връщат резултати от URL адреси при търсене на конкретно съдържание;
- през 1990 г. е създадена първата търсачка в интернет, която индексира само FTP файлове, но не и страници;
- през 1993 г. е създадена една от първите уеб търсачки - Wandex;
- през 1994 г. започва разработката на Yahoo! като университетски проект;
- през 1996 г. започва работата върху Google, който е официално основан като компания през 1998 г.;
- едва през 2009 г. Microsoft пуска търсачката Bing;
- други популярни интернет услуги са:
      - електронна поща - e-mail;
      - комуникация в реално време - chat.



            Видове web технологии
            
- Progressive web applications - PWA / Прогресивни уеб приложения
      - приложения в уеб, които могат да изглеждат като настолни приложения;
      - след инсталиране създават икона на екрана;
      - леки са и използват съвременни уеб технологии;
      - някои уеб приложения могат да работят и без интернет.

- Blockchain technology / Блокова верига
      - криптирана система за съхранение на база данни;
      - информация в блокове, която се свързва като верига;
      - устойчива на атаки, понеже не позволява промяна на данни;
      - позволява транзакции между потребители без намесата на трета страна;
      - напълно прозрачна технология.

- Internet of Things (IoT) / Интернет на нещата
      - комуникация чрез прехвърляне на данни между устройствата без постоянна човешка намеса;
      - приложение на технологията при камери, сензори, сигнално оборудване и други;
      
- Responsive Web Design / Адаптивен уеб дизайн
      - подход за уеб разработка, който се използва за приспособяване към различни размери на екрана;
      - сходен дизайн на уебсайт върху различни устройства независимо от размера на екрана;

                  CSS (Cascading Style Sheets)
                  

- файл, който е част от уеб страницата и определя нейния външен вид и подредба на елементите;
- именува стилове, които могат да бъдат прилагани за конкретни елементи от .html файла;
- централизирани стилове, които могат да се приложат за множество .html страници;
- синтаксис:      - свойство (property):    color, font-size.... 
                  - стойност (value):       blue, 9px....

- правила:        - свойствата и стойностите се разделят с двуеточие :
                  - всяка декларация завършва с точка и запетая   ;
                  - блокът за деклариране се обгражда с къдрави скоби {}
                  - коментарите започват с /* коментар */ и могат да бъдат на повече от 1 ред;

                  margin          - празното разстояние около елемента; 
                  border          - гранична линия около елемента, може да има дебелина и цвят;
                  padding         - вътрешното отстояние на елемента между текста и рамката;
            ______________________________      
            |           Margin           |
            |   ______________________   |
            |   | ______border______ |   |
            |   | |     padding    | |   |
            |   | |   __________   | |   |

            |   | |   |________|   | |   |
            |   | |________________| |   |
            |   |____________________|   |
            |                            |
            |____________________________|

                  height                      - задава височина на елемента
                  max-height                  - определя максимална височина на елемента;
                  min-height                  - определя минималната височина;
                  width                       - задава широчината на елемента; 
                  max-width                   - максимална широчина на елемента;
                  min-width                   - минимална широчина на елемента;

                  float: right;               - позициониране на елемент от дясно;
                  float: left;                - позициониране на елемент от ляво;
                  float: none;                - позициониране по подразбиране;
                  clear: both;                - предотвратява препокриване на елементи;

                  text-align: center;         - подравняване на текста в центъра;
                  text-align: left;           - подравняване на текста в ляво;
                  text-align: rigth;          - подравняване на текста в дясно;
                  text-align: justify;        - двустранно подравняване на текст;

                  font-size: 100px;           - размер на шрифт в пиксели;
                  font-size: 100%;            - размер на шрифт в проценти;
                  font-size: 2.5em;           - размер на шрифт;

                  position: static;           - стойност по подразбиране за позиция - зависи от цялостното оформление;
                  position: fixed;            - елементът не се влияе от нормалното си положение на страницата - не размества елементи;
                  positiion: relative;        - позиционира се спрямо нормалното си положение и зависи от другите елементи;
                  position: absolute;         - елементът с абсолютна позиция, различна от static;

                  overflow: visible           - препокритото съдържание се показва
                  overflow: hidden            - препокритото съдържание се скрива
                  overflow: Scroll            - показва скролбар за превъртане на скритото съдържание
                  overflow: auto              - скролбар се появява само, ако съдържанието прелее;
                  overflow-y: auto            - препокритото съдържание по вертикалата се показва със скролер
                  overflow-x: hidden          - препокритото съдържание по хоризонталата се скрива
                  z-index                     - определя реда на елементите при застъпване;

                  Жизнен цикъл на Web сайт 

- включва всички необходими стъпки от планирането до крайното внедряване и поддръжка;


      1. Проучване и анализ: 
            - разработчиците трябва да имат ясна представа за изискванията на възложителите или аудиторията;
                  - Предназначение
                        - каква е целта на уеб сайта - реклама, продажби, образование, информационен и т.н.;
                        - какъв тип ще е уеб сайта - търговски, информационен, новинатрски, продуктов и т.н.;
                        - каква е целевата аудитория - възраст, пол, предпочитания, професия и т.н.;
                  - Изисквания 
                        - има ли търсене на пазара? Защо потребителите биха го използвали?
                        - какви решения търсят потребителите и сайтът може ли да ги предложи?
                        - какви са най-добрите практики за този тип уебсайтове?
                        - има ли конкуренти или сходни сайтове и кои са те?
                  - Очаквания 
                        - кои функции и какво съдържание очакват потребителите?
                        - с какво ще допринесе уеб сайта за бизнеса/организацията?
                        - кои са подходящите текущи тенденции на уебсайта, който създаваме и т.н.?
                  - Друга допълнителна информация.



      2. Планиране:
            - разглежда се всичко, което ще бъде включено в проекта;
                  - концепция, цели, архитектура, технологии, ресурси, бюджет, екип и т.н.;
                  - тип на уеб сайта, целевата група, броя и типовете потребители, които ще обслужва;
                  - съставяне на екип за изработване и разпределение на ролите - ръководител, редактор, уеб дизайнер, 
                    уеб разработчик, QA и други;
                  - обсъждат се решения за оформлението на дизайна, страниците, съдържанието и т.н.;
                  - избират се езици за програмиране и софтуер, необходим за уеб приложенията;
            - създава се карта на сайта - йерархична съвкупност от всички страници, които изграждат един уеб сайт;
                  - прогнозират се срокове и се разпределят ресурсите;
                  - вземат се решения за брандирането на уеб сайта - лого, цветове, отличителни фрази и други.



      3. Проектиране и дизайн:
            - правят се скици - модели, графики и модел на уеб страниците и началната страница;
                  - определят се отделните елементи в съдържанието;
                  - разположение на бутони, текстови полета, менюта, раздели, картинки и т.н.;
            - избират се цветови теми, графики, графични обекти, заглавия и т.н. 
                  - съобразяват се с предназначението и целевата аудитория на сайта;
            - създава се прототип на сайта - опростено представяне на дизайн и функционалност;
                  - прави се демонстрация пред клентите и се показват основните функции.
                  


      4. Разработване:
            - етап, в който разработчиците пишат код и изграждат приложенията;
                  - съобразяват разработката с предишните етапи и спецификации;
                  - започва работата върху изграждането. 

            - Front-end уеб разработка:
                  - това е видимата част от уеб приложението, с което комуникира потребителя:

                        - .html файловете на всяка от уеб страниците:
                              Структурата на уеб страницата — като скелет. 
                              Определя какви елементи има: заглавия, параграфи, бутони, изображения и т.н.
                        - .css стилизирането на отделните елементи:
                              Визуалното оформление — цветове, шрифтове, разположение, анимации. 
                              Това е „дрехата“ на HTML-а.
                        - .js JavaScript, който осигурява "оживяването" на елементите:
                              Поведението и интерактивността — реагиране на действия на потребителя, 
                              динамично съдържание, анимации, валидиране на форми, и още.

            - Back-end уеб разработка - сървърна страна:
                  - разработване на функциите на уеб приложението;

                        - логика на приложението:
                              - правила и процеси за работа на системата;
                              - изчисляване на крайна цена на поръчка;
                              - обработване на потребителски заявки и т.н.
                        - работа с база данни:
                              - съхраняване, извличане, редактиране и изтриване на информация;
                              - потребителски профили, продукти, коментари, поръчки и други.
                        - интегриране на функции от страна на сървър-клиент;
                              - обработка на заявки от браузъра чрез HTTP, API, JSON/XML и т.н.
                              - PHP - лесен за начинаещи и широко използван от приложения като WordPress и Laravel;
                              - Python - четим и мощен, с много библиотеки - Django, Flask и др.;
                              - C# - стабилен и подходящ за корпоративни решения - ASP.NET;
                              - Java - с изключителни мащаби, използва се в банки и големи системи - Spring Boot;
                              - JavaScript - позволява JS на сървъра - Node.js и други;

                        - Бази данни
                              - Релационни: MySQL, PostgreSQL, SQL Server;
                                    - Таблици, връзки, SQL заявки;
                              - Нерелационни (NoSQL): MongoDB, Firebase;
                                    - Гъвкави структури, документи, JSON;

                        - Някои примери за Back-end разработки:
                              - Система за регистрация и вход;
                              - Онлайн магазин с количка и поръчки;
                              - Блог платформа с коментари и категории;
                              - API за мобилно приложение;
                              - Чат в реално време.

            - Как работи всичко заедно:
                  - Потребителят въвежда данни във front-end (например форма за регистрация);
                  - JavaScript изпраща заявка към сървъра (например чрез fetch() или axios);
                  - Back-end приема заявката, валидира данните, записва ги в база данни;
                  - Сървърът връща отговор (успешна регистрация, грешка и т.н.);
                  - Front-end показва резултата на потребителя.
