        Логически основи на компютърните системи

    Булева алгебра
    - последователност от преобразувания над двоични числа;
    - изпълняват се от различни логически схеми и устройства;
    - описание на логиката на тези действия за оптимизация на електронните схеми в компютърните системи;
    - Джорд Бул - XIX век развива идеята за използване на алгебрични методи в логиката;
    - булевата алгебра е в основата на функционирането на компютърните системи;
    - проверяват твърдения на естествен  език, които могат да се оценят като вярно или невярно;
            - 1 за истина / true;
            - 0 за лъжа / false. 

    - прости съждения с един отговор:
            пример: Желязото е метал = true   
    
    пример за по-сложни съждения с две или повече съставни, зависещи от връзките по между им - и или:
            пример за и (конюнкция):    Днес времето е топло и съм облякъл по-тънки дрехи.
                                           топло и тънки дрехи = и двете трябва да са = true за краен true

            пример за или (дезюнкция):  Утре ще съм на басейн или ще си остана вкъщи.
                                     басейн или вкъщи = едно от двете трябва да е = true за краен true

    - разликата при двата оператора е, че при И ако само едное false и крайният резултат е false;
    - при оператор ИЛИ e точно обратното, само едно твърдение да е true и крайният резултат ще бъде true;
    
    Логически променливи и функции 
    - методи за представяне:
            - словестно
            - таблично
            - аналитично
            - графично

    - логично отрицание !x - не е........ обръща резултата, ако твърдението е false става true и обратното.            
            пример с отрицание:     не е вярно, че днес съм бил на работа.    = работа false
            пример без отрицание:   днес цял ден съм бил на работа.           = работа true

    Диаграма на Вен

     |_____|_____|

     Логически (двоични) функции на две променливи 


     - конюнкция (AND) ^ &                  - истина само ако всички твърдения са вярни / true
            пример:                         - т.е. всичко трябва да е вярно
      ___________________________
      |   A   |   B   | A AND B |
      |-------|-------|---------|
      | false | false |  false  |
      | false | true  |  false  |
      | true  | false |  false  |
      | true  | true  |  true   |
      |_______|_______|_________|


     - дезюнкция (OR)  v ||                 - истина ако поне едно от твърденията е вярно / true
      ___________________________           - т.е. поне едно да е вярно
      |   A   |   B   | A OR B  |
      |-------|-------|---------|
      | false | false |  false  |
      | false | true  |  true   |
      | true  | false |  true   |
      | true  | true  |  true   |
      |_______|_______|_________|


     - сума по модул 2 (XOR)                - истина само ако едно от твърденията е вярно, при две true = false
      ___________________________           - т.е. вярно ако има само една истина като твърдение
      |   A   |   B   | A XOR B |
      |-------|-------|---------|
      | false | false |  false  |
      | false | true  |  true   |
      | true  | false |  true   |
      | true  | true  |  false  |
      |_______|_______|_________|


     - импликация (IF TRUE THEN)            - лъжа само ако първото твърдение е вярно / true, а второто невярно / false;
      ___________________________           - т.е. важна е връзката ако A е вярно, тогава B трябва да е вярно.
      |   A   |   B   | A -> B  |           - ако А е лъжа, няма значение дали B е лъжа, пак резултатът е истина / true
      |-------|-------|---------|
      | false | false |  true   |
      | false | true  |  true   |
      | true  | false |  false  |
      | true  | true  |  true   |
      |_______|_______|_________|


     - еквивалентност (IF AND ONLY IF)      - истина само ако всички твърдения са лъжа / false или всички са истина / true;
      ___________________________           - т.е. всичко true-true или false-false = true
      |   A   |   B   | A <-> B |
      |-------|-------|---------|
      | false | false |  true   |
      | false | true  |  false  |
      | true  | false |  false  |
      | true  | true  |  true   |
      |_______|_______|_________|


     - стрелка на Пиърс (NOR)               - истина само ако всички твърдения са лъжа / false. (обратното на OR)
      ___________________________           - т.е. AND на лъжата = true
      |   A   |   B   | A NOR B |
      |-------|-------|---------|
      | false | false |  true   |
      | false | true  |  false  |
      | true  | false |  false  |
      | true  | true  |  false  |
      |_______|_______|_________|


     - щрих на Шефер (NAND)                 - истина само ако има поне една лъжа / false; (обратното на AND)
      ___________________________           - т.е. OR на лъжата = true
      |   A   |   B   | A NOR B |
      |-------|-------|---------|
      | false | false |  true   |
      | false | true  |  true   |
      | true  | false |  true   |
      | true  | true  |  false  |
      |_______|_______|_________|
