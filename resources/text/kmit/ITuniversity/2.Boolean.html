        Логически основи на компютърните системи

        Булева алгебра

    - последователност от преобразувания над двоични числа;
    - изпълняват се от различни логически схеми и устройства;
    - описание на логиката на тези действия за оптимизация на електронните схеми в компютърните системи;
    - Джорд Бул през XIX век развива идеята за използване на алгебрични методи в логиката;
    - булевата алгебра е в основата на функционирането на компютърните системи;
    - проверяват твърдения на естествен  език, които могат да се оценят като вярно или невярно;
        - аргументи на булевата алгебра:
            - А и Б;    x и y;     твърдение 1 и твърдение 2 и т.н.
        - функции на булевата алгебра:
            - 1 за истина / true;
            - 0 за лъжа / false. 

        - прости съждения с един отговор:
                пример: Желязото е метал = true   
    
        - по-сложни съждения с две или повече съставни, зависещи от връзките по между им - и или:
                пример за "и" (конюнкция):    Днес времето е топло и съм облякъл по-тънки дрехи.
                                           топло и тънки дрехи - и двете трябва да са = true за краен true.

                пример за "или" (дизюнкция):  Утре ще съм на басейн или ще си остана вкъщи.
                                     басейн или вкъщи - едно от двете трябва да е = true за краен true.

    - разликата при двата оператора е, че при И (конюнкция) ако само едно условие е false - крайния резултат е false;
    - при оператор ИЛИ (дизюнкция) e точно обратното, само едно твърдение да е true и крайния резултат ще бъде true;
    
    Логически променливи и функции 
    - методи за представяне:
            - словестно
            - таблично
            - аналитично
            - графично

    - логично отрицание !x - не е........ обръща резултата, ако твърдението е true става false и обратното.            
            пример без отрицание:   днес цял ден съм бил на работа.           = true
            пример с отрицание:     не е вярно, че днес съм бил на работа.    = false

    Диаграма на Вен 
     _____________
     |  x  | !x  |
     |_____|_____|
     |  0  |  1  |
     |_____|_____|
     |  1  |  0  |
     |_____|_____|

_________________________________________________________________________________________________________________________________
                                    Логически (двоични) функции на две променливи 
_________________________________________________________________________________________________________________________________


     - Конюнкция (AND) ^ &                                                 - истина само ако всички твърдения са вярни / true
       пример: Ще отида на пикник, ако е слънчево И имам свободно време.   - т.е. всичко трябва да е вярно
      ____________________________________________________________      _____________________________
                  Условие              |   A   |   B   | A AND B |      |   x   |   y   |   x ^ y   |      
      ---------------------------------|-------|-------|---------|      |-------|-------|-----------|
      Не е слънчево, нямам време       | false | false |  false  |      |   0   |   0   |     0     |
      Не е слунчево, но имам време     | false | true  |  false  |      |   0   |   1   |     0     |
      Слънчево е, но нямам време       | true  | false |  false  |      |   1   |   0   |     0     |
      Слънчево е и имам време          | true  | true  |  true   |      |   1   |   1   |     1     |
      _________________________________|_______|_______|_________|      |_______|_______|___________|



     - Дизюнкция (OR)  v ||                                             - истина ако поне едно от твърденията е вярно / true
       пример: Ще гледам филм, ако съм уморен ИЛИ ми е скучно.          - т.е. поне едно да е вярно
      ___________________________________________________________       _____________________________       
                  Условие             |   A   |   B   | A OR B  |       |   x   |   y   |   x v y   |
      --------------------------------|-------|-------|---------|       |-------|-------|-----------|
      Не съм уморен, не ми е скучно   | false | false |  false  |       |   0   |   0   |     0     |
      Не съм уморен, но ми е скучно   | false | true  |  true   |       |   0   |   1   |     1     |
      Уморен съм, но не ми е скучно   | true  | false |  true   |       |   1   |   0   |     1     |
      Уморен съм и ми е скучно        | true  | true  |  true   |       |   1   |   1   |     1     |
      ________________________________|_______|_______|_________|       |_______|_______|___________|



     - сума по модул 2 (XOR)                                        - истина само ако едно от твърденията е вярно, при две true = false
       пример: Ще ям сладолед, ИЛИ ако е лято ИЛИ ако съм тъжен.    - т.е. вярно ако има само една истина като твърдение
               Но не и двете едновременно.
      ___________________________________________________________       _____________________________           
                  Условие             |   A   |   B   | A XOR B |       |   x   |   y   |   x ⊕ y  |
      --------------------------------|-------|-------|---------|       |-------|-------|-----------|
      Не е лято, не съм тъжен         | false | false |  false  |       |   0   |   0   |     0     |
      Не е лято, но съм тъжен         | false | true  |  true   |       |   0   |   1   |     1     |
      Лято е, но не съм тъжен         | true  | false |  true   |       |   1   |   0   |     1     |
      Лято е и съм тъжен              | true  | true  |  false  |       |   1   |   1   |     0     |
      ________________________________|_______|_______|_________|       |_______|_______|___________|



     - Импликация (IF TRUE THEN)                                     - лъжа само ако първото твърдение е вярно / true, 
       пример: Ако си обещал да дойдеш, тогава трябва да се появиш.    а второто невярно / false;
                                                                     - т.е. важна е връзката ако A е вярно, тогава B трябва да е вярно.
                                                                     - ако А е лъжа, няма значение дали B е лъжа, пак 
                                                                       резултатът е истина / true
     ____________________________________________________________       _____________________________
                 Условие              |   A   |   B   | A -> B  |       |   x   |   y   |   x → y   |                   
     ---------------------------------|-------|-------|---------|       |-------|-------|-----------|                   
     Не си обещал, не си дошъл        | false | false |  true   |       |   0   |   0   |     1     |                   
     Не си обещал, но си дошъл        | false | true  |  true   |       |   0   |   1   |     1     |                       
     Обещал си, но не си дошъл        | true  | false |  false  |       |   1   |   0   |     0     |
     Обещал си и си дошъл             | true  | true  |  true   |       |   1   |   1   |     1     |
     _________________________________|_______|_______|_________|       |_______|_______|___________|   



     - Еквивалентност (IF AND ONLY IF)              - истина само ако всички твърдения са лъжа / false или всички са истина / true;
       пример: Ще изляза навън само ако не вали.                    - т.е. всичко true-true или false-false = true
      ___________________________________________________________       _____________________________    
                  Условие             |   A   |   B   | A <-> B |       |   x   |   y   |   x ⇔ y   |
      --------------------------------|-------|-------|---------|       |-------|-------|-----------|
      Вали, не излизам                | false | false |  true   |       |   0   |   0   |     1     |
      Вали, излизам                   | false | true  |  false  |       |   0   |   1   |     0     |
      Не вали, не излизам             | true  | false |  false  |       |   1   |   0   |     0     |
      Не вали, излизам                | true  | true  |  true   |       |   1   |   1   |     1     |
      ________________________________|_______|_______|_________|       |_______|_______|___________|


     - стрелка на Пиърс (NOR)                               - истина само ако всички твърдения са лъжа / false. (обратното на OR)
       пример: Ще си почивам само ако не съм зает и не съм вдъхновен.           - т.е. AND на лъжата = true (нито x нито y)
      ___________________________________________________________       _____________________________        
                  Условие             |   A   |   B   | A NOR B |       |   x   |   y   |   x ↓ y   |
      --------------------------------|-------|-------|---------|       |-------|-------|-----------|
      Не съм зает, не съм вдъхновен   | false | false |  true   |       |   0   |   0   |     1     |
      Не съм зает, но съм вдъхновен   | false | true  |  false  |       |   0   |   1   |     0     |
      Зает съм, но не съм вдъхновен   | true  | false |  false  |       |   1   |   0   |     0     |
      Зает съм и вдъхновен            | true  | true  |  false  |       |   1   |   1   |     0     |
      ________________________________|_______|_______|_________|       |_______|_______|___________|


     - щрих на Шефер (NAND)                                 - истина само ако има поне една лъжа / false; (обратното на AND)
       пример: Ще се откажа от задачата, ако не е толкова важна и спешна.       - т.е. OR на лъжата = true (!x или !y)
      ___________________________________________________________       _____________________________        
                  Условие             |   A   |   B   | A NOR B |       |   x   |   y   |   x ↑ y   |
      --------------------------------|-------|-------|---------|       |-------|-------|-----------|
      Не е важна, не е спешна         | false | false |  true   |       |   0   |   0   |     1     |
      Не е важна, но е спешна         | false | true  |  true   |       |   0   |   1   |     1     |
      Важна е, но не е спешна         | true  | false |  true   |       |   1   |   0   |     1     |
      Важна е и спешна                | true  | true  |  false  |       |   1   |   1   |     0     |
      ________________________________|_______|_______|_________|       |_______|_______|___________|

                
      Булевата алгебра е от изключително значение за оптимизация работата на системите. 
      - чрез нея се повишава надежността и бързодействието;
      - запаметяват се дадени действие и алгоритми;
      - на базата на булевата алгебра е разработен изкуствения интелект.
