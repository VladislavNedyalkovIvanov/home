                    Назначаване на учител

            1. Създаване на профил в НЕИСПУО
                https://neispuo.mon.bg/portal -> Модул "Институции" - Подготовка и подаване на списък-обр. 1 -> 
                    -> Персонал -> Нов запис -> ЕГН -> Провери ->
                        *Ако има история в МОН тя излиза автоматично
                        *Ако е нов в системата - проверка в ГРАО 
                    -> Въвеждане на данни;
                Длъжност -> Номер по ред, Длъжност 1 
                    -> Категория: педагогически/непедагогически персонал;
                    -> Длъжност: титуляр/заместник;
                    -> Щат: 1 или 1/2; Учител, общообразователен предмет в...;
                    -> Щатно/нещатно място по:                  пр. История и цивилизации;
                    -> Основна специалност, по която преподава: 
                    -> Основание по КТ:                         Безсрочен  ТД чл. 67, ал. 1, т. 1 от КТ (титуляр)
			        
                                Срочен                          ТД по чл. 68, ал. 1, т. 1 от КТ (титуляр за опр. срок)
                                Бележки:                        Във връзка с чл. 70 от КТ;
                                            
                                Срочен                          ТД по чл. 68, ал. 1, т. 3 от КТ (заместник);
                                и т.н....

                    -> Назначен към: Училище - от бюджет;


                1 вариант - Преподавателска заетост:    
                    - Добавяне на свободните часове;
          
                2 вариант - Учебен план:                
                    -> Паралелки в които преподава -> 
                    -> Раздел А: учебен предмет -> Норма на предмета: 30, 648, 684 или 700;
                    -> Преподаватели: Нов запис -> Име на преподавател и норма на предмета -> Запази;
                    Учител -> Преподавателска заетост -> Редакция -> Запази;
                    -> Проверка на норматив;


            2. Профил в @gmail.com (домейн_на_училище.com) -> Admin console;
                -> Directory -> Add user -> First name -> Last name;
                -> fistname.lastname@домейн_на_училище.com;
                -> Secondary email -> Личен имейл за възстановяване на парола на служителя;

                Намиране на потребителя в търсачката -> Groups -> Add user to groups:
            
                - sbu@домейн_на_училище.com                 (синдикати); 
                - teachers@домейн на училище.com            (всички учители);
                - pro.etap@домейн_на_училище.com            (прогимназия); 
                - n.etap@домейн_на_училище.com              (начален етап);
                - klasni@домейн_на_училище.com              (всички класни); 
                - klasni-pro.etap@домейн_на_училище.com     (кл. прогимназия);
                - klasni-n.etap@домейн_на_училище.com       (кл. начален).


            3. На пощата КОД ПО НЕИСПУО@edu.mon.bg се изпращат от системата (tbs-sds@edu.mon.bg) 
               всички акаунти в @edu.mon.bg, което става автоматично след регистрация в НЕИСПУО;

                - Следва да се препратят имейлите с потребителско име и парола към @домейн_на_училище.com профилите;


            4. Създаване на профил в Shkolo.bg:
                Администрация -> Добави -> Въвеждане на данни -> Активен -> Потребителско име и парола за вход;
                -> Роля -> Добави;
	            или
                Чрез синхронизация в НЕИСПУО -> Администрация -> Образец 1 или МОН -> 
                -> Потребител -> Активен -> Потребител и парола;


            5. Изпращане на данните за вход във всички акаунти към имейл адресът в @домейн_на_училище.com;
